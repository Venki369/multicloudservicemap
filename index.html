Easy to get wrong

Network scope

A GCP VPC is global, with regional subnets. An AWS VPC or Azure VNet stays inside one region.

Subnets differ

An AWS subnet lives in one AZ. Azure and GCP subnets cover the whole region.

Global is not outage-proof

The IAM, Route 53 and CloudFront control planes lean on us-east-1, so trouble there can reach them.

Names global, data not

S3 buckets and Azure storage accounts need globally unique names, but the data sits in one region.

Azure resource groups

A resource group has a region for its metadata, yet it can hold resources from any region.

Pick the spread early

Cloud Storage, BigQuery and Spanner ask for region, dual-region or multi-region when you create them.
